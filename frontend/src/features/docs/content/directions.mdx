## Direction count defines how freely a character can move.

A direction is one view of the same character. More directions make movement more natural, but each added view must preserve pose, equipment, and lighting.

## Match direction count to real movement

### One direction

Use one direction for static portraits, side-view characters, or objects with a fixed orientation.

<OneDirectionExample />

### Four directions

Use front, back, left, and right as the practical starting point for top-down movement.

<FourDirectionExample />

Each view should retain the same silhouette, weapon position, and lighting direction. This swordsman set shows the four cardinal views needed for a top-down character.

### Eight directions

Add the four diagonals when the game includes diagonal movement, aiming, or smoother turning. Do not select eight directions by default; they need more consistency work.

<EightDirectionExample />

The basketball player set adds north-west, north-east, south-west, and south-east views. Compare each diagonal with its neighboring cardinal directions before using it in animation.
