## A reference is a visual constraint, not just inspiration.

### Introduction

A clear reference tells the generator which proportions, colour treatment, silhouette, and equipment must remain consistent. Start with one primary image that establishes the result you want.

### Choose references that answer a specific question

- Keep the character's proportions, clothing silhouette, and key equipment.
- Match lighting direction and colour treatment to the target asset.
- Use a clean image with an unobstructed, generously framed subject.
- Add supporting references only for local material or equipment detail.
- When images disagree, state which one defines the final result.

### Keep the prompt explicit

Use the reference to establish the visual language, then name the details that cannot change. If a weapon, hairstyle, or colour matters, include it in the prompt. This keeps a supporting image from accidentally changing the primary reference's perspective or style.
